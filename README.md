# Blender 每日学习计划

一个纯静态网页，配合一份 30 天的 Blender 新手学习计划：每天 30–45 分钟，从认识界面到完成一个综合小项目。

## 使用方法

直接用浏览器打开 `index.html` 即可（或用任意静态服务器托管，例如 GitHub Pages）。

- 每天打开网页，完成「今日任务」卡片里的清单，勾选完成的小任务，写点笔记。
- 点击「完成今天」记录进度，解锁下一天，同时更新连续天数、累计分钟、成就徽章。
- 「完整路线图」可以查看所有 30 天的安排，回看之前的笔记。
- 进度保存在浏览器本地（`localStorage`），换设备或清缓存会丢失。

## 文件结构

- `curriculum.js` — 30 天课程内容数据（可自行增删/调整每日任务）
- `index.html` — 页面结构
- `style.css` — 深色主题样式（配色致敬 Blender 橙）
- `app.js` — 进度存储、连续天数计算、成就徽章、彩带动画等交互逻辑

## 部署到 GitHub Pages（可选）

仓库设置里开启 Pages，选择当前分支和根目录即可，无需构建步骤。
